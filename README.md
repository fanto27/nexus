# NEXUS - Cyber Security Framework

NEXUS est un framework de cybersécurité modulaire, conçu localement pour l’apprentissage, les environnements de laboratoire (CTF), et les audits défensifs.

## Fonctionnalités
- Scan TCP asynchrone à haute performance
- Cartographie réseau (Graphes)
- Génération de rapports HTML/Markdown
- Architecture "Ethical-by-Design" (ActionGate)
- Base de données SQLite locale

## Avertissement Légal
*NEXUS est un framework développé à des fins éducatives et d’audit autorisé. L’auteur décline toute responsabilité quant à l’utilisation de cet outil sur des systèmes sans le consentement explicite de leurs propriétaires.*
